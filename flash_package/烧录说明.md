# ESP32-S3-RLCD-4.2 便携烧录包使用说明

本目录可直接整体拷贝到任意 Windows 10 或 Windows 11 电脑上执行固件烧录，目标电脑无需安装 ESP-IDF、Python 或其他开发环境。

## 硬件与固件参数

- 开发板型号：`waveshare-s3-rlcd-4.2`（Waveshare ESP32-S3-RLCD-4.2）
- 主控芯片：`esp32s3`
- Flash 配置：`16MB` / `DIO` / `80MHz`
- 固件默认波特率：`460800`（传输不稳定时可改用 `115200`）

## 目录结构

```text
flash_package/
├── flash.bat          双击启动烧录菜单（Windows 10/11 通用入口）
├── flash.ps1          独立 PowerShell 烧录逻辑（自动识别串口与偏移地址）
├── 烧录说明.md        本说明文档
├── tools/
│   └── esptool.exe    独立版 Windows ESP 烧录工具（免 Python 环境）
└── firmware/
    ├── xiaozhi-rlcd42_full_<时间戳>.bin   完整固件（烧录至 0x0）
    ├── xiaozhi-rlcd42_app_<时间戳>.bin    仅 App 固件（烧录至 0x20000）
    └── xiaozhi-rlcd42_build_<时间戳>.log  编译日志、文件大小与 SHA-256 校验值
```

## 固件类型与 16MB 分区表

`firmware/` 目录中提供两类镜像文件：

1. **完整固件（`*_full_*.bin`）**：已合并引导程序、分区表、OTA 数据、主程序与资源分区，烧录偏移为 `0x0`。适合新开发板、整片擦除后恢复或跨版本升级。
2. **仅 App 固件（`*_app_*.bin`）**：仅包含主程序代码，烧录偏移为 `0x20000`。适合本机版本日常迭代，会保留设备原有的 Wi-Fi 配网和 NVS 数据。

当前使用的 16MB 分区表（对应 `partitions/v2/16m.csv`）：

| 分区名称 | 类型 / 子类型 | 起始偏移 | 分区大小 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| bootloader | - | `0x0` | - | 二级引导程序 |
| nvs | data / nvs | `0x9000` | `16 KB` (`0x4000`) | Wi-Fi 配置与用户参数 |
| otadata | data / ota | `0xd000` | `8 KB` (`0x2000`) | OTA 启动槽位记录 |
| phy_init | data / phy | `0xf000` | `4 KB` (`0x1000`) | 射频校准参数 |
| ota_0 | app / ota_0 | `0x20000` | `4.94 MB` (`0x4F0000`) | 默认主程序分区 |
| ota_1 | app / ota_1 | `0x510000` | `4.94 MB` (`0x4F0000`) | 备份 OTA 分区 |
| assets | data / spiffs | `0xA00000` | `6 MB` | 语音资源与字体镜像 |

## 硬件准备与进入下载模式

1. 使用具备数据传输能力的 USB Type-C 数据线连接电脑与开发板 USB 接口。
2. 多数情况下 `esptool.exe` 会通过 DTR/RTS 信号自动复位进入下载模式。
3. 若串口未出现或自动握手失败，请手动触发下载模式：
   - 按住开发板上的 `BOOT`（GPIO0）按键保持不放；
   - 点按一次 `RESET` 按键后松开；
   - 松开 `BOOT` 按键。

## 双击交互烧录步骤

1. 将整个 `flash_package` 文件夹复制到目标电脑任意路径（建议保持 `flash.bat`、`flash.ps1`、`tools/`、`firmware/` 在同一目录下）。
2. 双击运行 `flash.bat`。
3. 菜单中输入 `1` 并回车，进入固件烧录流程：
   - **选择固件**：列表按时间倒序排列，`[完整 0x0]` 对应 `*_full_*.bin`，`[App 0x20000]` 对应 `*_app_*.bin`，直接回车选择编号 `1`。
   - **确认偏移地址**：脚本会自动填充 `0x0` 或 `0x20000`，直接回车确认。
   - **选择串口**：脚本会自动列出所有 COM 口及 USB 设备名称，输入序号或串口号（例如 `COM4` 或 `4`），也可输入 `R` 刷新列表。
   - **选择波特率**：直接回车使用默认 `460800`，连线较差或遇到校验失败时可输入 `115200`。
   - **确认执行**：核对信息后输入 `Y` 并回车，等待进度条到达 `100%` 且设备自动硬复位运行。

菜单额外提供：
- `[2]` 读取芯片与 Flash ID，验证串口连接是否正常；
- `[3]` 整片擦除 Flash（需输入大写 `ERASE` 确认）。

## 命令行手动烧录参考

在 `flash_package` 目录下打开终端，可直接调用捆绑工具进行脚本化操作（请将 `COM4` 与固件文件名替换为实际值）：

烧录完整固件（`0x0`）：

```powershell
.\tools\esptool.exe --chip esp32s3 -p COM4 -b 460800 --before default_reset --after hard_reset write_flash --flash_mode dio --flash_size 16MB --flash_freq 80m 0x0 ".\firmware\xiaozhi-rlcd42_full_20261124_111500.bin"
```

仅更新 App 固件（`0x20000`）：

```powershell
.\tools\esptool.exe --chip esp32s3 -p COM4 -b 460800 --before default_reset --after hard_reset write_flash --flash_mode dio --flash_size 16MB --flash_freq 80m 0x20000 ".\firmware\xiaozhi-rlcd42_app_20261124_111500.bin"
```

读取开发板 Flash ID 验证通信：

```powershell
.\tools\esptool.exe --chip esp32s3 -p COM4 flash_id
```

擦除整片 Flash：

```powershell
.\tools\esptool.exe --chip esp32s3 -p COM4 erase_flash
```

使用 `flash.bat` 单行静默烧录最新固件示例：

```bat
flash.bat -Firmware "xiaozhi-rlcd42_full_20261124_111500.bin" -Port COM4 -Yes
```

## 常见问题排查

- **找不到 COM 口**：检查是否使用了仅供电的充电线；查看 Windows“设备管理器 -> 端口 (COM 和 LPT)”，如有黄色感叹号请安装对应 USB 转串口驱动（CH340/CP210x）或使用开发板原生 USB-JTAG 口（按住 `BOOT` 点按 `RESET` 后通电）。
- **串口被占用（Access denied / Could not open port）**：关闭正在使用同一 COM 口的串口监视器、串口助手或其他 IDE。
- **提示 `A fatal error occurred: Failed to connect to ESP32-S3`**：按上述“进入下载模式”按键时序操作后重新开始烧录。
- **烧录中途校验失败或超时**：更换更短的 USB 数据线、改插电脑主板原生 USB 口，并在波特率提示处输入 `115200`。
- **新电脑提示安全拦截或脚本被锁定**：从压缩包或网络下载后如遇系统拦截，请在 `flash_package` 目录运行以下 PowerShell 命令解除文件锁定：

```powershell
Get-ChildItem -Recurse | Unblock-File
```

## 开发者编译与打包更新

在开发机 `xiaozhi-esp32` 目录下运行 `make.bat`：
- 选择 `[1]` 编译最新固件并自动合并、拷贝产物到 `flash_package/`；
- 选择 `[3]` 直接把当前 `build/` 已有编译结果同步打包到 `flash_package/`；
- 如需输出到自定义目录，可通过命令行指定 `-PackageDir`：

```bat
make.bat -Action pack -PackageDir "D:\Share\RLCD42_Flash"
```
